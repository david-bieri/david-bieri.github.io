# Outlet marks

Every file here is either a **typographic placeholder** (generated by `tools/build_media.py`, contains `<text>`) or an **official mark** you dropped in. The coverage band on `media.html` and the home page shows the 16 outlets listed in `BAND` in `tools/build_media.py`. A placeholder there is shown as the outlet's name in Archivo; an official mark is shown as the mark itself.

## Adding an official mark

1. Get the one-colour (black or white) vector version from the outlet (see the table). Not a PNG, and not from logo-aggregator sites.
2. `python3 tools/prep_logo.py ~/Downloads/<file>.svg <slug>`: sets the ink to `currentColor` and cut-outs to the page colour, strips fixed sizes, refuses rasters and scripts, and warns about multi-colour files.
3. `python3 -m http.server`, then open `media.html`. Check the mark at desktop and phone widths, in light and dark mode. If it looks small, the artboard has padding: crop it in the source.
4. `python3 tools/prep_logo.py --check` lists which band slots still have placeholders.

Ask before using any mark, and only as "Coverage includes": never anything that suggests endorsement.
